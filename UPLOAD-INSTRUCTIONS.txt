TUFFEDK — V2 PREMIUM

1. Extract this ZIP.
2. Open your GitHub repository:
   tuffedk.github.io
3. Upload/replace ALL existing website files with the files inside this folder.
4. Commit changes to main.
5. Settings → Pages.
6. Confirm:
   Branch: main
   Folder: /(root)
7. Save if needed.
8. Wait 1–3 minutes.
9. Press Ctrl + F5 to refresh the live website.

IMPORTANT:
- Upload the files inside the ZIP, not the ZIP itself.
- This version keeps all assets at the root level to avoid broken image paths.
